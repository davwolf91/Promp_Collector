# Preferencias globales

## Idioma y comunicación
- Responde siempre en español
- Sé conciso: código primero, explicación después
- Cuando propongas cambios, muestra el diff relevante, no el archivo entero

## Entorno
- OS: macOS / Linux
- Editor: VS Code con terminal integrada
- Node.js: v22 LTS
- Gestor de paquetes: npm

## Estilo de código personal
- Prefiero async/await, nunca .then()
- Prefiero funciones arrow para callbacks
- Mensajes de commit en inglés con Conventional Commits (feat:, fix:, chore:, docs:)
